## What RuForge is


RuForge is a free, open-source Windows desktop application published by its maintainer, who operates on GitHub as UnboundAngel (referred to below as **"the maintainer"**). It is built on yt-dlp and FFmpeg and includes a media player. It downloads media from YouTube and other sites that yt-dlp supports, indexes downloaded files in a local library, and plays them back. How it handles your data is described in the [Privacy Policy](/legal/privacy).
