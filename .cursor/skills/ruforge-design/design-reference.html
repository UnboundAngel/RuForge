Avoid

  • Morph menus (a chip that grows into a menu): removed from the app. Never rebuild one; use the Music menu kit. Morph.tsx now only holds MORPH_SPRING.
  • Drawn-underline headings: website only (website/src/components/ui/animated-underline-text-one). The app copy was removed; app headings use .font-display.
  • Hand-rolled horizontal scrollers (overflow-x-auto plus a local mask): use EdgeSquishScroll.
  • See-through blurred fills (the old .glass classes, now deleted): against the solid-surface rule.
  • Raw img with a hand-written onError: use FallbackImg (or useImageFallback when two imgs share one source), or the collection helpers MusicPlaylistCover, ChannelAvatar and LikedSongsCover.
  • title="…": use data-tooltip.
  • --music-card-radius: read in two files but never defined.
  • motion/react vs framer-motion: both are installed (76 vs 38 files). Morph and overlays use motion/react.

Consolidate later

Places where one job has several separate implementations instead of one shared helper. Until each is merged, build new work on the target and never add another variant.

  • Marquee: MarqueeText lives inside DownloadJobQueuePanel.tsx beside HoverMarqueeText. Target: both in one shared ui file.
  • Animation library: motion/react and framer-motion. Target: motion/react only.

Normal depth is tonal. A shadow is a signal: this floats (menu, dialog), or content scrolled under a sticky header.
